# Análisis de Asistencias y Notas con Jupyter Notebook

Este proyecto contiene un análisis de datos de asistencias y notas de estudiantes utilizando pandas, matplotlib y SQLAlchemy en un entorno Jupyter Notebook.

## Requisitos
- Python
- Jupyter Notebook
- Bibliotecas:
  - pandas
  - matplotlib
  - sqlalchemy
- Clonar este repositorio
```bash
    git clone https://github.com/MarceloOrtegaDev/modelo_examen_tlp3_ortega_marcelo.git
```
- Crear tu entorno virtual
```bash
    pythom -m venv venv
```

## Ejecutarlo e instalar las dependencias

```bash
    pip install -r requirements.txt
```
